接入你自己的机器人

FishChat 会在这台电脑开一个机器人接入端口，你的机器人程序（Python / Node / 任意语言）连上来就能聊天。

  1. 地址：ws://127.0.0.1:3210
  2. 机器人连上后 5 秒内发送 {"type":"hello","name":"小Q"}
  3. 用户发消息时，机器人收到 {"type":"message","text":"...","attachments":[...]}
  4. 机器人回复 {"type":"reply","text":"...","attachments":[...]}
  5. 附件用 base64：{"type":"image","name":"a.png","data":"<base64>"}

示例机器人：bot/bot_example.py（安装 pip install websockets 后直接运行即可看到效果）。

设置

消息通知
窗口不在前台时，收到机器人消息弹出系统通知
开机自启动
登录 Windows 后自动打开 FishChat（桥也会跟着启动）
关闭窗口后继续在后台运行
点 X 时收进托盘，桥不断开、消息照常接收；托盘图标里可以重新打开或退出
